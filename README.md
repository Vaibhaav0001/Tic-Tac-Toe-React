🎮 Tic-Tac-Toe Game
This is a simple and interactive Tic-Tac-Toe game built using HTML, CSS, and JavaScript. It's a classic two-player game where the players take turns marking the spaces in a 3×3 grid with X or O. The game shows the winner at the end, or a draw if there is no winner. A reset button allows users to play again easily.

✨ Features
🧠 Two-player gameplay

🎉 Displays the winner or draw message at the end

🔁 Reset button to start a new game

📱 Responsive design – works on different screen sizes

🧼 Clean and simple UI

🛠️ Technologies Used

React-For building the UI components and managing state

HTML – Structure of the game

CSS – Styling and layout

JavaScript – Game logic and interactions

🚀 How to Play
Open the game in a browser.

Player X starts the game.

Players take turns clicking on empty cells.

The game will automatically detect a win or draw.

Click Reset to play again.

📂 Setup Instructions
Clone the repository:
git clone (https://github.com/Vaibhaav0001/Tic-Tac-Toe-React)

Navigate to the project directory:
cd tic-tac-toe-react
Install dependencies:

npm install
Start the development server:
npm start dev
